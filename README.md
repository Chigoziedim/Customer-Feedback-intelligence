# Customer Feedback Intelligence
### Reputation Monitoring & Service Quality

## Overview
This project automates customer feedback processing and reporting using n8n, AI sentiment analysis, Google Sheets, Fillout, and Power BI.

It helps businesses organise feedback, identify customer sentiment, flag serious complaints, and monitor service quality through a visual dashboard.

## Tools and Technologies
- **n8n:** Workflow automation and conditional routing.
- **AI analysis:** Sentiment classification and feedback assessment.
- **Google Sheets:** Feedback storage and tracking.
- **Fillout:** Customer feedback collection form.
- **Power BI:** Dashboard reporting and visualisation.

## Workflow
1. Customers submit feedback through an online form.
2. The submission triggers an automated workflow.
3. AI analyses the feedback.
4. Conditional logic routes feedback based on sentiment, severity, and review requirements.
5. The workflow records the processed feedback in Google Sheets.
6. Power BI presents feedback trends and management indicators.

## Dashboard Highlights
- Total feedback received.
- Positive and negative feedback counts.
- Sentiment distribution.
- Manager alerts and review statuses.
- Service-quality monitoring.

## Business Value
The solution helps teams identify dissatisfied customers, prioritise issues, reduce manual feedback handling, and make data-informed service improvements.
